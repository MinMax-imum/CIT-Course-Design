
# CIT-Course-Design
The open source part of the computer interface technology course design.
计算机接口技术课程设计中的开源部分。

This project originated from the Computer Interface Technology course I studied between late 2021 and January 2022. As part of the course requirements, I completed these course design assignments. At that time, I selected content suitable for open source release and created this repository.

这个项目来自 2021 年底到 2022 年 1 月我学习的计算机接口技术课程，其结课要求之一就是完成这些课程设计题目。当时选择了一些可以开放的内容，创建并开源到了这个仓库。

Several years later, I now intend to undertake secondary development and supplement additional content to enhance this project.

几年后的现在我打算尝试一些二次开发或补充一些内容，以增强这个项目。

This project was previously named `ComputerInterfaceTechnology_C_D`, and the link is `https://github.com/MinMax-imum/ComputerInterfaceTechnology_C_D.git`. It has now been changed to a more appropriate name, `CIT-Course-Design`, and the link has changed accordingly. To access the original completed version from that time, you can switch to the `completed-20220104` branch. The `main` branch also maintains the original state unchanged. All new modifications and developments are currently being implemented in the `sec-dev` branch.

这个项目之前名称是 `ComputerInterfaceTechnology_C_D`，链接是 `https://github.com/MinMax-imum/ComputerInterfaceTechnology_C_D.git`，现在已改为更合适的名称 `CIT-Course-Design`，链接也随之变化。查看当年开发完成的版本，可以切换到 `completed-20220104` 分支。`main` 分支也保持了原始状态未变。所有新的修改和开发目前都在 `sec-dev` 分支中进行。

├── designTest1/                # Design Test 1: Hexadecimal to ASCII conversion
│   ├── desiginDescription1.txt     # Design requirements description

│   └── design1(Xingyan).asm        # Alternative implementation

│   ├── designDescription2.txt      # Design requirements description
│   ├── design2.asm                 # Assembly implementation
│   └── design2InPython.py          # Python reference implementation
├── designTest3/                # Design Test 3: Sorting algorithm

│   ├── design3.asm                 # Assembly implementation
│   ├── design3InC.c                # C reference implementation
│   ├── design3InC.exe              # Compiled C executable
│   └── design3InPython.py          # Python reference implementation
├── designTest4/                # Design Test 4
│   ├── design4.asm                 # Assembly implementation
│   └── designDescript4.txt         # Design requirements description
├── designTest5/                # Design Test 5
│   ├── design5.asm                 # Assembly implementation
│   └── DesignDescription5.txt      # Design requirements description
├── designTest6/                # Design Test 6
│   ├── design6.asm                 # Assembly implementation
│   └── designDescription6.txt      # Design requirements description
